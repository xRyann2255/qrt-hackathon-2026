Q2. Word search generation

Build the smallest N × N letter grid that contains every required word in a straight line (8 directions) and no forbidden word anywhere. The grid wraps at the edges. Each test scores by density, the letters of the required words over N²: full marks at 1.7. Full question

Runs the submitted C++ annealer (descending N), compiled to WebAssembly. The submission also held 18 grids computed offline on lab machines for the hidden tests; that table is removed here. The live annealer alone scored 665.1 of 1080; the table took it to 833.40.
