QRT x Imperial "Code. Compute. Compete" 2026: interactive solutions

Team Mite (solo): 1st of 68 teams with 3987.89 of 4300 points, 26 October 2026. Problems by QRT. Each page below runs the solver from the competition in your browser on input you choose.

  • Q1. Square packing: enter side lengths, see the packing, its area and its score.
  • Q2. Word search generation: enter words, get the smallest wrapping grid the annealer finds.
  • Q4. Masyu: place pearls or generate a puzzle, see the solver's loop.
  • Q5. Document Lego: paste text, watch it get cut up, scrambled and reassembled.

Q3 was a black box with no picture to draw. The C++ solvers are the submitted code compiled to WebAssembly, with the tables of answers computed offline for the hidden tests removed; each page says how the code it runs relates to the submission.
