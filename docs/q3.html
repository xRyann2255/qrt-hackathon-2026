Q3. Black box

The whole statement: “Query the black box to maximise payoff. Beware the noise.” Each of the 51 tests feeds the program one number t; it prints a list of numbers and gets a noisy payoff. A test scores 20 × (payoff / best possible payoff), clipped to 0 to 1. Full question

Probing showed the payoff is mean(g·f) − 0.5·mean(f²) for a hidden curve g that depends on t, so the best answer is f = g. The submission stores g for each t as Fourier coefficients, read off one probe at a time, and scored 1020 of 1020. How it was found

Scores marked measured are HackerRank's, for the answers submitted with 5, 11 and 21 waves and for the final answer; the rest are computed from the recovered model. Each wave's size was read off two probes, then a residual pass corrected all 100 with one probe each. g is drawn from the final answer, which scored 20 of 20 on every test, so it matches the hidden curve to within rounding.
