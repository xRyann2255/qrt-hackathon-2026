Q3. Black box

The whole statement: “Query the black box to maximise payoff. Beware the noise.” Each of the 51 tests feeds the program one number t; it prints a list of numbers and gets a noisy payoff. A test scores 20 × (payoff / best possible payoff), clipped to 0 to 1. There is nothing to draw, so this page has no demo. Full question

Probing showed the payoff is mean(g·f) − 0.5·mean(f²) for a hidden curve g that depends on t, so the best answer is f = g. The submission stores g for each t as Fourier coefficients, read off one probe at a time, and scored 1020 of 1020. How it was found
